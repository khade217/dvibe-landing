# Dvibe - Premium Accessories Landing Page

A modern, responsive landing page boilerplate for **Dvibe**, featuring premium accessories with a Modern Vintage aesthetic.

## 🎨 Design Features

### Color Palette
- **Muted Coral**: #F2A17F (Primary Warm)
- **Sage Green**: #A3D1B5 (Primary Cool)
- **Deep Forest**: #1B3B36 (Accent Dark)
- **Cream**: #F9F4E8 (Neutral)
- **Gold/Brass**: #D4AF37 (Detail Accent)

### Typography
- **Headings (Pacifico)**: Script font for logo and hero text
- **Subheadings (Montserrat)**: Clean geometric sans-serif
- **Body (Inter)**: Highly readable sans-serif for descriptions

## 📋 Sections Included

1. **Navigation Bar** - Sticky navigation with smooth scroll
2. **Hero Section** - Eye-catching intro with CTA buttons
3. **About Section** - Brand values and mission
4. **Features Section** - Key selling points
5. **CTA Section** - Call-to-action with dark background
6. **Contact Section** - Contact form
7. **Footer** - Links, social media, copyright
